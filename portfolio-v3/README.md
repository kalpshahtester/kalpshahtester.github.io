# Kalp Shah — Portfolio V3

A recruiter-focused QA portfolio built for GitHub Pages.

## Architecture
- Semantic HTML for accessible structure
- Modular CSS with responsive design and reduced-motion support
- Lightweight JavaScript for navigation, typing, counters, workflow animation, and QA simulation
- Local Lottie animation asset to avoid depending on an external animation host
- No framework or build step required; GitHub Pages can publish static HTML/CSS/JS directly

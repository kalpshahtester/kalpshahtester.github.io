# Kalp Shah — Manual QA portfolio

Vite + vanilla JavaScript portfolio with a restrained Three.js wireframe scene, semantic HTML, reduced-motion fallback and evidence-backed QA content.

## Setup

```bash
npm install
npm run dev
npm run build
```

Set GitHub Pages to **Settings → Pages → Source → GitHub Actions**. After deploying, verify the three routes, 360px mobile layout, Safari/Firefox, keyboard navigation, reduced motion and Lighthouse.

SauceDemo is a public practice application; MakeMyTrip is a testing assessment. Neither is presented as production work. The 100+ metric refers to IT support experience from 2020–2025.
